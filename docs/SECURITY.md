# Security

Synchronic is a static site: it has no accounts, takes no personal data and runs no server code beyond serving its pages. Security issues are still possible, for example a way to inject script through data files or URL parameters, or a compromised dependency.

## Reporting a vulnerability

Please report it privately through GitHub: on the repository's **Security** tab, choose **Report a vulnerability**. Do not open a public issue.

Include what you found, how to reproduce it, and what an attacker could do with it. We aim to reply within a week, and will credit you in the fix unless you would rather not be named.

## Not security issues

Wrong dates, names, flags or labels are data errors, not vulnerabilities. Please use the [data error](https://github.com/hashemi42/Synchronic/issues/new?template=data-error.yml) form.

## Supported versions

Only the current `main` branch, which is what the site deploys.
